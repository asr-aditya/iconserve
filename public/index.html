For AI agents

Machine-readable docs live at /llms.txt. Three ways in:

  • Guessable URLs — /i/{name}.svg (best match) or /icons/{set}/{name}.svg.
  • JSON API — /api/search?q=…, /api/icon, /api/sets. OpenAPI at /openapi.json.
  • MCP server — connect an MCP client to /mcp. Tools: search_icons, get_icon, list_sets.
